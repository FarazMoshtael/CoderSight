##
- Blazor Server rendering application CMS web application

## Build & Run
- dotnet build
- dotnet run

## Configuration
- wwwroot/appsettings.json is the base config, wwwroot/appsettings.{Environment}.json overrides matching keys.

## UI
- The UI is rendered based on saved block components content inside database. 
- There are multiple lock types as blazor razor components which are available on admin side to make a page for website.
